# 🚌 Bus Management & Booking System

A full-stack **Bus Management and Booking System** developed using **Django REST Framework (DRF)** and **React.js**.

The project provides a RESTful backend API with a modern React frontend for managing bus operations, routes, schedules, passengers, bookings, and related information.

## 🚀 Tech Stack

* **Backend:** Python, Django, Django REST Framework
* **Frontend:** React.js
* **Database:** SQLite / PostgreSQL
* **API:** RESTful APIs
* **Authentication:** Token/JWT-based authentication
* **UI:** React, HTML, CSS, JavaScript

## ✨ Main Features

* 👤 User authentication and authorization
* 🚌 Bus management
* 🛣️ Route management
* 🕐 Schedule management
* 🎫 Bus booking management
* 👥 Passenger management
* 📋 Booking and reservation details
* 🔐 Role-based access
* 🔄 REST API integration
* 📱 Responsive React interface
* 📊 Management dashboard

## 🏗️ Project Architecture

The application follows a **full-stack architecture**:

**React Frontend → REST API → Django REST Framework → Database**

The React application communicates with the Django backend through RESTful APIs, providing a separation between the frontend and backend layers.

## 🎯 Project Goal

The goal of this project is to build a practical, scalable, and user-friendly bus management platform while gaining hands-on experience with **Django REST Framework, API development, React.js, authentication, database management, and full-stack application development**.
